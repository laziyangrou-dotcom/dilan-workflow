# 帝蓝工作流-统一审核端-V46

支持美术 / 分镜 / 视频工程包的本地项目管理、导入审核、制作流程只读预览、动态分镜预览、表单导出和审核结果导出。

## 使用
1. 双击 `安装.bat` 安装依赖。
2. 双击 `start.bat` 启动审核端。
3. 打开后进入项目管理页面，导入制作端工程包。

## V2 更新
- 打开工具后先进入项目管理页面；导入工程包会生成本地审核工程。
- 素材/图片/视频工程包导入时会检测模块，不匹配会询问是否切换。
- 修复美术工程包容易被识别为分镜模块的问题。
- 动态分镜支持图片/视频总进度条拖动预览；视频支持连续播放。
- 动态分镜视频预览自适应浏览器最大区域，避免不同比例视频导致尺寸跳变。
- 制作流程页面改为更接近制作端工作台的只读布局，并显示模型字段。
- 表单导出参考模板格式，并加入成本列与总成本。


## 安装与启动

1. Windows 下双击 `安装.bat`。
2. 安装完成后双击 `start.bat` 启动。
3. 如果旧版本脚本曾进入 Python 的 `>>>` 交互界面，请先输入 `exit()` 退出，再使用本版本的 `安装.bat`。


## V4 更新
- 项目管理改为父项目 → 美术 / 分镜 / 视频 → 子项目结构。
- 导入工程包时读取包内父项目、子项目和模块信息，自动归位；没有父项目时自动创建。
- 工程包在任意模块入口导入均可自动进入对应模块。
