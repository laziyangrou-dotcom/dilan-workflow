# 帝蓝工作流-视频部分-V9

本工具是基于「帝蓝工作流-制作端-V1」改造的视频生成版本，保留原来的项目、SC、子栏、标签页、待选分镜和右侧分镜操作流程，将原生图链路替换为 Seedance 2.0 生视频链路。

## V9 更新说明

- 进一步修复双击预览视频时“全屏视频 + 页面中屏弹窗视频”同时存在的问题。
- 视频双击预览不再打开页面中间的预览弹窗；优先让被双击的原视频元素直接进入浏览器全屏。
- 如果从存储库点击视频预览，会使用一个临时全屏播放器；退出全屏后自动暂停、卸载并移除，不在页面中留下中屏播放器。
- 打开全屏前会关闭旧预览弹窗并暂停页面内其它音视频，避免双重音频。
- 图片和音频仍保留原来的页面弹窗预览逻辑。
- 保留 V7 的 Seedance 2.0 详细报错显示、技术详情和后端终端详细日志能力。

## 使用方式

1. 第一次使用先双击 `安装.bat`，它会在项目根目录创建 `.venv` 虚拟环境并检查依赖。
2. 双击 `start.bat` 启动。
3. 浏览器打开：`http://localhost:8787`。
4. 在右上角填写火山方舟 Ark API Key。
5. 先创建父级项目，再创建子项目；进入子项目后按原帝蓝流程操作。

## 本版主要功能

- 保留帝蓝工作流原有的父级项目、子项目、SC 父栏、子栏、标签页、待选分镜和右侧分镜区域逻辑。
- 标签页内保留设置区与引用素材区，取消聊天式生图，改为 Seedance 2.0 视频提示词框。
- 生成结果区改为视频结果区，生成后可播放、删除、加入待选分镜。
- 待选分镜区域由图片改为视频。
- 最右侧分镜区域按原图片逻辑显示视频。
- 素材库分类扩展为：人物、场景、道具、音频、视频。
- 提示词支持 `@素材名` 引用当前项目素材；人物、场景、道具作为参考图，音频作为参考音频，视频作为参考视频传入 Seedance 请求。
- 生成视频默认保存到 `output/video/`。
- 导出工程包时会包含项目 JSON、素材库、生成视频、临时引用素材和统计文件。
- 为后续并入「帝蓝工作流-制作端-V1」预留兼容结构，视频记录仍保留部分原字段名以减少合并成本。

## 目录说明

- `input/`：项目素材库文件，按人物、场景、道具、音频、视频分类保存。
- `output/video/`：Seedance 生成视频和手动加入的待选视频。
- `projects/`：父级项目、子项目和工程 JSON 数据。
- `config.json`：默认模型、比例、分辨率、时长等设置。
- `usage.json`：运行后自动生成，用于记录用户消耗统计。
- `exports/`：导出工程包时自动生成。

## 注意

- 本版需要火山方舟 Ark API Key 才能真实调用 Seedance 2.0。
- 后端已迁移提交任务、轮询任务、解析视频 URL、下载视频到本地的核心流程。
- 由于没有内置 API Key，压缩包内无法直接验证真实生成结果；需要你填入自己的 Ark API Key 后测试。
- 如果本地大体积音频/视频参考素材被 Ark 接口拒绝，后续可以再改成“先上传到可访问 URL，再传 URL”的模式。
