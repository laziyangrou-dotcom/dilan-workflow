# 帝蓝工作流-整合版-V47

本整合版包含两个独立模块：美术 / 视频。

两个模块作为独立子服务运行，核心代码、项目数据、素材库、输出目录彼此分开；统一通过项目管理页选择父项目，再在右侧切换模块并创建/打开对应模块下的子项目。

工程包、素材包支持导出为本地 ZIP 与从本地 ZIP 导入，便于备份与在不同电脑之间迁移。

## 目录结构

```text
帝蓝工作流-整合版-V38/
├─ integrated_server.py
├─ start.bat
├─ 安装.bat
├─ 安装
├─ requirements.txt
└─ tools/
   ├─ material/              # 美术模块，核心独立
   └─ video/                 # 视频模块，核心独立
```

## 使用方式

第一次运行：

1. 双击 `安装.bat`
2. 安装完成后，双击 `start.bat`
3. 浏览器会自动打开 `http://127.0.0.1:8787/material`

后续运行：

- 直接双击 `start.bat`

## 端口

- 统一入口：`8787`
- 美术子服务：`8790`
- 视频子服务：`8789`

如果端口被旧版本占用，请先关闭旧版本工具。
