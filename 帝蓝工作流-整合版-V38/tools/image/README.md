# 帝蓝工作流-制作端-V1 Tool

本工具是本地运行的对话式生图分镜工具。

## 使用方式

1. 第一次使用先双击 `安装.bat`，它会在项目根目录创建 `.venv` 虚拟环境并检查依赖。
2. 双击 `start.bat` 启动。
3. 浏览器打开：`http://localhost:8787`
4. 首次进入会要求填写昵称，用于右上角消耗金额统计。
5. 先创建父级项目，再在父级项目中创建子项目；进入子项目后开始正式操作。

## 本版主要功能

- 项目管理改为：父级项目 → 子项目 → 工作台。
- 新建子项目时可填写初始分镜范围：分镜【起】到【止】；两个都不填则创建空子项目。
- 分镜范围只允许数字，允许左右相等，例如 12 到 12 会创建 `SC-0012`。
- SC 父栏编号支持点击修改，显示为四位数补零；编号不能重复。
- 新增 SC 永远按当前最大 SC 编号 + 1 创建，不会自动补空缺。
- 修改 SC 编号后，父栏会按编号从小到大重新排序，子栏编号会跟随父栏显示变化。
- 每个 SC 的子栏内支持标签页：新建、复制、关闭、切换、拖动排序。
- 新建标签页是纯净页面，不带历史聊天和生图结果。
- 设置区、引用素材、聊天区、生图结果属于标签页。
- 右侧“待选分镜空栏”属于整个子栏，不随标签页切换。
- 聊天区生成图支持删除记录，但不会删除 `output/image` 文件夹里的实际图片。
- SC 表头新增起止时间输入：时 / 分 / 秒。
- 子栏表头新增时长秒数输入。
- 右上角显示当前昵称和累计消耗美元。
- 支持导出当前子项目为完整工程包 ZIP，包含 `manifest.json`、`export_info.json`、`usage_summary.json`、工程 JSON、素材、输出图片和临时引用素材。
- 工程包使用当前昵称作为项目负责人；费用统计会精确汇总到每个当前存在的 SC，已删除 SC 的历史费用会保存到隐藏查账区。

## 目录说明

- `input/`：项目素材库文件。
- `output/image/`：生成图片输出目录。
- `projects/`：父级项目、子项目和工程 JSON 数据。
- `config.json`：默认模型、比例、质量、token 单价等设置。
- `usage.json`：运行后自动生成，用于记录用户消耗统计。
- `exports/`：运行后导出工程包时自动生成，用于临时保存导出的 ZIP。

## 注意

- 不填写 OpenAI API Key 时，工具会生成 MOCK SVG，占位测试流程，不会产生真实 API 消耗。
- 计费统计优先使用 API 返回的 token usage；图片接口若没有返回 usage，会按分辨率、质量、提示词和参考图数量做估算。
