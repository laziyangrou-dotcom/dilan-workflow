# 帝蓝工作流-美术模块 V20

这是从图片工具独立出来的素材生成模块，作为整合版中的第三个核心模块运行。

## 入口

- 统一入口：`http://127.0.0.1:8787/material`
- 子服务端口：`127.0.0.1:8790`

## 主要结构

- 顶部大类顺序：`素材 / 视频 / 图片`
- 素材模块核心文件位于 `tools/material/`，与 `tools/image/`、`tools/video/` 独立。
- 素材工作台包含三个工作区：`人物`、`场景`、`道具`。
- 人物/场景工作区保留父栏 + 子栏结构，但父栏不再显示时分秒，子栏不再显示秒数。
- 道具工作区为单层子栏结构。
- `待选分镜` 文案已调整为 `待选素材`。

## 后续预留

素材项目数据中已预留素材模块工作区结构，后续可以继续追加“审核通过后导出素材包，并导入素材/视频/图片素材库”的功能。
